# SwiftMed Urgent Care

A modern, high-craft, single-page web application for **SwiftMed Urgent Care + Outpatient Clinic** located in Elkridge, MD (Howard County, Route 1 corridor).

Built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## Features

- **Skip the Waiting Room**: Frictionless virtual queue with live wait-time updates and interactive check-in flow.
- **The SwiftMed Guarantees**:
  - *Under 8-Minute Lobby Arrival Standard*
  - *Seen in 20 or Copay Free* (Off-peak promise: Mon–Fri 9am–12pm & 2pm–5pm)
  - *Hospital-Grade Diagnostics On Site* (Digital X-Ray, Point-of-Care Ultrasound, and rapid CLIA-certified labs)
- **Interactive Clinical Services**: Curated tabs for Everyday Illness, Minor Injuries & Sutures, Imaging & Diagnostics, and IV Hydration Suite & Physicals.
- **Transparent Pricing**: Clear \$140 flat self-pay visits, \$35–\$45 sports physicals, and major insurance acceptance (BCBS, Aetna, Cigna, UHC, Medicare, Maryland Medicaid).
- **Interactive Virtual Queue Modal**: 2-step online registration with instant queue ticket confirmation and simulated SMS alerts.
- **Emergency Triage & Disclosures**: 911 alert bar, location & operating hours (Mon–Fri 8am–8pm, Sat–Sun 9am–5pm), and compliance notices.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Plus Jakarta Sans & Outfit (via `next/font/google`)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
npm run start
```
